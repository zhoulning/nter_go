# 面试跟踪管理系统（Interview Go）需求文档

- 版本：v1.18（2026-09-05 全量同步至当前实现）
- 状态：M1–M3 已交付、可日常使用；M4 部分完成
- 说明：本文档已按代码实际实现（前后端 + 数据库）全量修订，功能条目均标注实现状态（✅ 已实现 / 🔜 未实现）；历史修订记录见文末。

---

## 1. 项目概述

### 1.1 背景

用户即将启动社招求职，需要一个**个人本地工具**来管理整个面试周期：从投递岗位、面试前准备、面试中应对，到面试后复盘沉淀。核心诉求是"准备有依据、过程有跟踪、复盘有沉淀"，并且随着面试场次增多，系统的题库和经验积累要让后续面试越来越容易。

### 1.2 目标

1. **进度可视化**：所有投递的公司/岗位集中管理，流程状态一眼看清，面试排期不遗漏。
2. **准备有依据**：针对每个岗位做调研和匹配度分析，明确"这家公司要什么、我还差什么、该重点准备什么"。
3. **预测被问什么**：基于 JD、简历和历史题库，AI 预测每轮面试可能的问题，并通过 AI 模拟面试实战对练。
4. **复盘有沉淀**：上传真实面试录音（或直接粘贴文字稿），转写后自动切题、逐题点评，形成复盘报告；真实被问的题沉淀进题库（错题本），反哺下一轮预测。

### 1.3 非目标（明确不做）

- 不做多用户 / 登录系统（单机单人使用）。
- 不做云端同步、自动投递简历、爬虫抓取岗位。
- 不做移动端 App（Web 页面做基本响应式即可）。
- 不追求企业级健壮性，以个人好用为第一标准。

### 1.4 关键决策记录（已与用户确认）

| 决策项 | 结论 |
|---|---|
| 运行形态 | 本地 Web 应用，一条命令启动并自动打开浏览器 |
| 技术栈 | Python FastAPI + Vue 3 + SQLite |
| 大模型 | 智谱 GLM（做通用 OpenAI/Anthropic 兼容适配层，可随时切换） |
| 录音转写 | 双通道：本地 faster-whisper（默认）+ 云端 ASR（可选加速） |
| 进度主视图 | 看板 + 日历双视图 |
| 扩展功能 | 题库/错题本、简历版本管理、统计漏斗、Offer 对比（全部纳入第一版） |
| UI 风格 | 简约明亮风（Linear/Notion 气质），深色模式列入后续 |
| 岗位方向 | 后端/服务端开发（出题维度按此预置，保留自定义能力） |

## 2. 功能需求（对齐当前实现）

### 2.1 模块一：面试进度跟踪 ✅

#### 2.1.1 机会（岗位）管理 ✅

- 一个"机会"= 一家公司的一个岗位。字段：公司名、岗位名称、部门/团队（选填）、城市、**工作地址**（详细地址，AI 提取时自动识别）、薪资范围、投递渠道、优先级（S/A/B）、状态、投递时间、**关联简历**（该岗位投递所用版本，默认简历带 ★）、工作描述（`jd_text`，职责/要求/福利等统一存放，保留原文分段）、备注。
- **状态机**（看板列）：`想投 → 已投递 → 面试中 → Offer → 接受`。社招笔试场景少，不设独立「笔试」状态，笔试作为该机会下的一条面试轮次记录。
- 支持手动新增、编辑、删除（级联二次确认）。
- **AI 快速填充** ✅：新增/编辑时粘贴 JD 文本（任意站点）或职位链接自动提取字段：
  - 猎聘（liepin.com）链接：服务端直抓直解析，秒出结果、不耗 AI 额度；
  - BOSS直聘 / 智联招聘 / 脉脉链接：通过 CDP 直连用户自己已登录的专用浏览器，抓取页面全文后交 LLM 结构化（不依赖 CSS 选择器，对改版免疫；Patchright 反检测内核兜底，参数自动剥除；含登录墙/安全验证检测与引导）；
  - 被动「提取当前页面」模式：读取专用浏览器当前打开的职位页，零导航零注入。

#### 2.1.2 轮次管理 ✅

- 每个机会下多轮面试事件，轮次类型：笔试 / 一面 / 二面 / 三面 / 交叉面 / HR 面 / 其他。
- 每轮字段：轮次类型、计划时间、实际时间、形式（现场/视频/电话/笔试系统）、面试官姓名与背景（选填）、结果（待定/通过/挂/未参加）、结果通知时间、面试纪要（Markdown）。
- 轮次可在「面试日历」页与岗位详情页「轮次与录音」Tab 内增删改。

#### 2.1.3 看板 / 列表双视图 ✅

- **看板视图**：卡片展示公司名、岗位、优先级色条、下一轮面试时间、当前停留天数；拖拽跨列改状态。
- **列表视图**：表格展示全部机会（机会、状态、优先级、城市、薪资、渠道、下场面试、停留天数、操作），点击行进详情页。
- **多维度筛选**（两视图共用）：状态 / 优先级 / 渠道 / 城市 多选 + 关键字搜索（公司/岗位/城市），实时显示命中数，一键清空；筛选条件写入 URL（如 `?city=上海,深圳`），刷新/分享不丢。

#### 2.1.4 面试日历 ✅

- 自研月视图 + 周视图，展示所有已排期轮次，按结果着色（待定/通过/挂了/未参加）。
- 点击日期查看当日安排；支持在日历内直接新增/编辑/删除轮次。

#### 2.1.5 首页 Dashboard ✅（默认落地页）

- 问候语与日期；四张统计卡片：在跟进 / 未来 7 天面试 / 近 7 天投递 / 累计 Offer（可点击跳转）。
- **未来 7 天面试列表**：按天分组，显示时间/公司/轮次，可直达。
- **待办提醒**：按类型聚合为可执行卡片（补填面试结果 / 想投超期 / 补充工作描述），点击公司标签直达看板并自动按该公司过滤。
- 最近更新机会速览。

### 2.2 模块二：面试前调研与岗位匹配度评估 ✅

#### 2.2.1 调研笔记 ✅

- 每个机会下五大板块（每板块各一条）：公司调研 / 团队与业务 / 技术栈调研 / 自我介绍稿（可按公司定制）/ 反问清单。
- Markdown 编辑与轻量渲染（自研零依赖 MarkdownView）。
- 一键 AI 调研提纲：按板块定制 Prompt（自我介绍稿引用关联简历、只允许真实内容并标注【检查】；调研类提纲一律「（待补充）」占位、禁止编造公司数据）；已有内容覆盖前二次确认。

#### 2.2.2 岗位匹配度评估（AI）✅

- 输入：工作描述 + 关联简历（可在详情页换任意简历版本重新评估）。
- 输出**匹配度报告**：岗位画像（硬性要求/技术栈/软性要求/加分项）、逐条匹配（6–10 条，权重 + ✅匹配/⚠️部分/❌缺失 + 简历原文证据 + 建议）、总分 0–100 + 五维雷达图（技术栈/经验/项目/软素质/发展契合）、准备重点 3–5 条、简历追问风险。
- 报告每岗位保留最新一份；可删除重生成、导出 Markdown。评分标准在 Prompt 内锚定，要求严格判定。

### 2.3 模块三：题目预测、模拟面试与题库 ✅

#### 2.3.1 AI 题目预测 ✅

- 输入：工作描述 + 关联简历 + 城市与薪资范围 + 匹配度报告缺口摘要 + 题库参考（不会/模糊的弱项维度加权覆盖，近期真实被问题避免原样重复）+ 目标轮次（笔试/一面/二面/三面/交叉面/HR 面，各轮次侧重不同）。
- 出题难度按公司层级 / 城市竞争烈度 / 薪资年限校准（大厂 / 知名独角兽题更深更偏原理，中小厂偏基础落地；高薪资深岗多考原理、架构与线上实战，初级岗以基础为主）。
- 输出**预测题单**，按维度分组：八股基础（后端方向预置维度，可自定义）/ 项目深挖（按追问链设计）/ 场景设计 / 软素质 / 反问建议；每题附考察意图、参考答题要点、难度。
- 每个（岗位 × 轮次）保留最新一份；**自测模式**：一键隐藏全部要点、逐题「看要点」揭晓。

#### 2.3.2 AI 模拟面试 ✅

- 对话式模拟：选择轮次开始后 AI 面试官生成开场与第一问（已生成题单的轮次优先按题单出题）。
- 面试官根据回答质量自动决定**追问（每题最多 1 次）或进入下一题**；支持「跳过此题」（对话留痕、分析中标记未回答不计分）。
- **语音转写容错**：候选人口述回答经语音转文字产生的同音字/术语错写（如「瑞迪斯」=Redis），面试官按上下文推断本意理解，不因错别字扣分或纠缠。
- **按公司层级/城市/薪资/年限校准**：面试官、评分、出题三类 Prompt 均先判断目标公司的业界面试难度（大厂更严、中小厂宽松）与所在城市竞争烈度，再叠加薪资年限的职级期望决定出题 / 追问深度与评分宽严。
- **量化结果只考核项目 / 场景类题目**：纯八股 / 原理题答到点上即算完整——面试官不追问「落到你项目里效果如何 / 有没有量化指标」，分析也不因没结合项目 / 没有数字而扣分或记入问题；量化数字只对项目 / 场景 / 案例类题目有要求（bad 示例、评分锚定与示范答案规则均按题型区分）。
- 点击「结束面试」生成整场分析：总评分（0-100，只基于已回答题目；三维各附 1-5 评分细则，总分由逐题小分推导——已答题折算平均为基础分，模型总分钳制在基础分 ±5 内，按「能否通过该公司该轮」的通过线语义解释）、逐题复盘（回答摘述 + 结构/深度/表达三维打分 + 亮点/问题 + 参考答案）、薄弱维度、行动清单、题目一键入题库。
- 对话记录与分析全部入库，左侧会话列表可回看/删除，进行中的会话可随时继续。

#### 2.3.3 题库 / 错题本 ✅

- 题目字段：题干、维度分类（后端方向预置 15 类，可自定义输入）、难度、来源（手动/真实面试/AI 预测）、我的回答要点、参考答案要点、自评分（1-5）、掌握状态（不会/模糊/已掌握）。
- **题目来源多对多**：一道题可关联多家公司的多场面试，卡片显示「字节跳动 · 二面」式标签，多来源折叠为「A 等 N 处」；可标记「因哪版简历被问到」，搜索覆盖题干/维度/来源公司/简历名。
- **AI 口述版答案**：每题一键生成第一人称面试现场表达的口述版答案（结论先行 + 编号要点，250–400 字，项目/场景题按 STAR 展开），支持重新生成；「答案详情」浮框内呈现我的要点 + 口述版（Markdown 排版渲染）+ 参考要点。
- **错题本视图**：自动圈出「不会/模糊或自评 ≤ 3」的题，支持标记已掌握、已复习。
- 预测新岗位题目时，AI 自动参考题库弱项维度加权，实现"越用越准"。

### 2.4 模块四：录音/文字复盘 ✅

#### 2.4.1 两种复盘形态 ✅

- **录音复盘**：上传 mp3/m4a/wav/aac（建议单文件 ≤ 2 小时），本地存储，展示时长、大小、转写状态（待转写/转写中/已转写/失败）。
- **文字复盘** ✅：现场面试等无录音场景，直接粘贴问答记录/面经文字稿（关联岗位/轮次），立即生成复盘报告。

#### 2.4.2 转写（双通道）✅

- **本地通道（默认）**：faster-whisper，后台线程任务执行、进度可见，不阻塞界面；模型大小在设置中切换。
- **云端通道（可选）**：兼容 OpenAI Whisper API 协议的云端 ASR（设置中配置 base_url + key），适合长录音快速出稿。
- **声纹说话人区分** ✅：sherpa-onnx 说话人嵌入 + 贪心聚类（短段跳过，最多区分 2 个说话人）；模型/依赖缺失时自动降级为按语义切题，不影响主流程。

#### 2.4.3 文字稿管理 ✅

- **AI 矫正稿**：对原始转写稿一键 AI 矫正（修正转写错别字、统一说话人标记为「面试官/我」），原始稿与矫正稿双稿对照；两份稿均支持手动编辑保存。
- 页面支持边听（播放器）边看文字稿；也支持用飞书妙记等外部工具转好后粘贴。

#### 2.4.4 AI 复盘报告 ✅

- 基于转写文字稿生成（长稿分段切题 + 汇总 map-reduce 两阶段），包含：
  1. **自动切题**：识别面试官的问题列表，每题关联我的回答要点摘述；
  2. **逐题点评**：回答质量三维打分（结构完整性/技术深度/表达清晰度，各 1-5）+ 亮点 + 问题 + 参考答案要点；
  3. **JD 对照**：结合岗位工作描述逐条判断各题展示情况；
  4. **面试官关注点分析**：从提问分布推断面试官关注点与团队技术侧重；
  5. **薄弱维度 + 行动清单**：下一轮面试前要补的具体事项；
  6. **真题沉淀**：识别出的真实题目一键入题库（自动带上机会 + 轮次来源，标记「真实面试」），后续预测会参考薄弱维度。
- 🔜 **预测命中对比**（原规划：与事前预测题单比对命中率）暂未实现，列后续里程碑。

### 2.5 模块五：扩展功能

#### 2.5.1 简历库与简历 AI ✅

- 上传多版简历（PDF/DOC/DOCX ≤ 20MB），自动抽取纯文本（PyMuPDF 按版面坐标优先、pypdf 回退；DOCX 用 python-docx）；支持下载、改名、备注、删除、重新抽取。
- **AI 结构化整理** ✅：机器抽取的原文自动按五大板块整理为结构化 Markdown（个人信息/教育背景/专业技能/工作经历/项目经历 + 其他信息），只修格式禁止编造；上传时自动整理，已上传的可补跑，「整理后 / 原文」切换对照。
- **默认简历** ✅：全局唯一，投递关联、匹配度评估与预测自动使用。
- **背景信息说明** ✅：目标方向、工作年限、期望、求职诉求、特殊情况（Gap/转行）等，AI 体检与出题的重要依据。
- **AI 简历体检** ✅：得分总览（0-100 环形图 + 分档 + 建议分级统计 + 五维推导基础分）+ 五维评分卡（内容完整性 / 亮点与量化 / 经历说服力 / 表达简洁度 / 岗位匹配度，各 1-5 分带横条展示）+ 6–8 条优化建议（标题/具体改法/级别：硬伤-加分-锦上添花），要求引用简历真实位置。
- **简历维度预测面试题** ✅：基于简历内容生成 8 道「追问式」面试题（针对项目、数字、技术选型），附维度标签与可折叠参考答案要点。
- **简历详情页**（`?page=resume-detail&id=N` 可直达）：身份区（格式图标、名称、默认/体检得分徽标、文件元信息）+ 三页签（结构化简历 / AI 简历体检 / 预测面试题），体检与出题页签顶部共用背景信息卡。

#### 2.5.2 统计漏斗看板 ✅

- ECharts 转化漏斗：投递 → 进入面试 → 到达终面 → Offer → 接受，含各环节转化率徽章。
- 辅助图表：机会状态分布环图、近 8 周投递/面试活跃柱状图、渠道效果表（投递/约面/约面率/Offer）。

#### 2.5.3 Offer 对比决策 ✅

- Offer 录入：月薪/月数/签字费/股票/福利/加班/通勤 + 五维主观评分，支持清除重录。
- 五维雷达图对比、明细对比表（年薪估算、加权总分自动高亮推荐）；五维决策权重可调，存浏览器本地。

#### 2.5.4 数据管理

- ✅ 关键数据（匹配度报告）支持导出 Markdown。
- 🔜 一键备份（SQLite + 上传文件打包 zip）/ 恢复导入：未实现，列后续里程碑。

### 2.6 系统设置 ✅

- **AI 设置**：API Key、模型、base_url（兼容任意 OpenAI / Anthropic 协议端点，按 base_url 自动识别；系统代理不可用时自动直连重试；推理型模型输出为空时自动加倍 max_tokens 重试）。
- **浏览器直连**：CDP 调试端口地址 + 使用引导（一键脚本 `start-boss-browser.bat` 启动专用浏览器）。
- **转写设置**：本地模型大小、云端 ASR 配置。
- 🔜 外观（深色模式）、数据备份恢复：未实现，列后续里程碑。
- AI Key 本地存储，数据不上传第三方（除用户主动触发的 AI 接口）。

## 3. 页面结构与信息架构（当前实现）

## 5. 技术架构

### 5.1 总体

```
┌─────────────────────────────── 本机 ───────────────────────────────┐
│  浏览器 (Vue 3 SPA)                                                │
│      │  HTTP (localhost:8000)                                      │
│  FastAPI（单进程）                                                  │
│   ├── REST API（13 组路由）                                         │
│   ├── 静态托管         生产模式直接托管前端构建产物（单命令启动）      │
│   ├── 后台任务线程池    转写 / AI 矫正 / AI 报告生成（异步、带进度）   │
│   ├── SQLite (SQLModel)  data/app.db（WAL）                        │
│   ├── faster-whisper   本地转写 + sherpa-onnx 声纹说话人区分          │
│   ├── Patchright / CDP  直连用户浏览器提取职位页（BOSS/智联/脉脉）     │
│   └── LLM 适配层  ───→  智谱 GLM（OpenAI/Anthropic 兼容协议，可换端点）│
└────────────────────────────────────────────────────────────────────┘
```

### 5.2 技术选型明细（实际使用）

| 层 | 选型 | 说明 |
|---|---|---|
| 后端框架 | FastAPI + Uvicorn | 自带 API 文档（/docs），异步适合长任务轮询 |
| ORM | SQLModel（SQLAlchemy + Pydantic） | 与 FastAPI 的 Pydantic 模型一体，代码量小 |
| 数据库 | SQLite（WAL 模式） | 零运维，单用户并发足够 |
| 前端框架 | Vue 3 + Vite + TypeScript | 跨组件通信用 provide/inject（未引 Pinia） |
| UI 组件 | Naive UI + Tailwind CSS | 简约明亮风 |
| 图表 | ECharts（自封装 VChart 组件） | 漏斗、雷达、饼图、柱状图 |
| Markdown | 自研 MarkdownView（零依赖） | 笔记/报告/答案渲染 |
| 看板拖拽 / 日历 | 原生实现 | 看板拖拽、月/周日历均自研，未引第三方库 |
| 本地转写 | faster-whisper | 免费离线、CPU 可跑 |
| 说话人区分 | sherpa-onnx 声纹嵌入 + 贪心聚类 | 模型缺失自动降级为语义切题 |
| 职位页提取 | 猎聘服务端直抓；BOSS/智联/脉脉 CDP 直连 + Patchright | 不依赖 CSS 选择器，LLM 结构化 |
| LLM | 智谱 GLM（OpenAI/Anthropic 兼容端点） | 统一适配层：JSON mode + 重试 + 超时 + 代理直连回退 |

### 5.3 关键技术设计

1. **长任务处理**：转写、AI 矫正、AI 报告生成为后台线程任务（带任务锁防重复触发），前端轮询状态接口展示进度。
2. **LLM 适配层**：统一封装 `chat(messages, json_schema?)`，支持 JSON mode + 解析失败自动重试 + 超时；兼容 OpenAI / Anthropic 双协议（按 base_url 自动识别）；系统代理不可用时自动直连重试；推理型模型输出为空时自动加倍 max_tokens 重试。
3. **结构化输出**：匹配度报告、题单、复盘切题、模拟面试分析等均要求模型按 JSON Schema 输出，解析失败自动重试，保证前端渲染稳定。
4. **文件解析**：PDF 用 PyMuPDF 按版面坐标抽文本（pypdf 回退）；DOCX 用 python-docx；音频 ffprobe 读时长。
5. **启动方式**：使用阶段 `python run.py`（托管 frontend/dist 并自动打开浏览器）；开发阶段 uvicorn --reload + vite dev（/api 代理）。
6. **数据库迁移**：`create_all` 建新表 + 启动时 PRAGMA 检查补列（ALTER TABLE），存量数据自动回填，无需手动迁移。

## 7. 非功能需求

1. **性能**：页面首屏 < 1s（本地）；转写与 AI 任务后台化不阻塞界面。
2. **隐私**：数据全部本地；录音与简历仅在本机处理（云端转写/AI 调用除外，且仅用户主动触发，调用什么模型在设置页明示）。
3. **可靠性**：AI 调用失败不影响手工数据；任务失败可重试（带任务锁防并发重复）。
4. **易用性**：新用户零引导可用（表单直白）；空状态有引导按钮；关键删除操作二次确认；URL 可直达任意页面。
5. **兼容**：Chrome/Edge 最新版；1280px 以上宽度优先，基本响应式兼容窄窗口（侧边栏折叠为图标栏）。
